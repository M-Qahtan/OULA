# OULA scenario and design acceptance

The founder's instruction dated 18 October 2026 (Asia/Riyadh) makes the cinematic scenario the experience reference and «تصميم شعار عُلا» the visual reference. Earlier screen work is preserved. Later five-family gateway decisions take precedence over the older six-world agent taxonomy.

## Product contract

- Desktop retains the cinematic identity: night Riyadh, the continuous OULA ring, restrained illuminated accents and a contextual assistant.
- Mobile simplifies controls, navigation and family selection; it does not silently remove the journey.
- Top-level families: PULSE / نبض, HABITAT / موئل, NEXUS / وصل, FORGE / هندسة, CIVIC / مدن. The older PRISM label is an internal investment/decision lens, not a sixth primary gateway.
- Role selection shapes presentation. Only server identity, membership, purpose, consent and scopes grant authority.
- The assistant currently offers deterministic local routing. Voice, persistent personal memory and generative autonomous execution are not represented as active services.
- Fact, declared input, inference, simulation, recommendation, human decision and authorized action retain separate meanings.

This matrix preserves the complete scenario as the target. A passing local buyer/owner journey does not certify completion of the entire cinematic future vision.
