# OULA Intelligence Kernel — Forward-Compatible Hooks

The Riyadh MVP does not build FEM, CFD, BIM authoring, city simulation or autonomous engineering. It does preserve the minimum canonical objects required to grow toward those capabilities without rebuilding the core.

## Added canonical hooks
- **Evidence** — provenance-bearing support for facts, observations and decisions.
- **SimulationRun** — reproducible record of a model/solver run and its assumptions, inputs, uncertainty and validation.
- **EngineeringArtifact** — vendor-neutral reference to future plans, models, calculations, BIM/IFC objects, reports and simulation outputs.
- **Authority requirement** — recommendations declare who or what must approve an action.
- **Uncertainty** — recommendations expose uncertainty rather than hiding it in a single confidence number.
- **Decision authority / approval reference** — the accepted action remains attributable to a real authority.
- **Outcome evidence** — real-world results can be supported by observations/evidence and used later for calibration.

## Rule
These are data/contract hooks only. Heavy engineering solvers remain separate research tracks until OULA has the validated use case, data and professional governance required to operate them safely.
