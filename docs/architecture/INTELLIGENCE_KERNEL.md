# OULA Intelligence Kernel — executable foundation

Canonical loop:

Facts / Intent / Match → Recommendation → Human Decision → Transaction / Action → Outcome → Learning.

The executable kernel defines Observation, Assumption, ModelVersion, Recommendation, DecisionRecord and Outcome.

The kernel never owns People, Property, Spatial or Transaction truth. It consumes authorized state, produces traceable analysis artifacts, and returns proposals. Engineering brains, simulations, Physical Truth, Outcome Genome and Built World models must implement these same contracts later instead of creating parallel AI architectures.
